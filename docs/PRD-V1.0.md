# Windows 机器名修改工具(Computer Rename Tool)
## 产品需求文档(PRD)V1.0

> **版本说明**:本 PRD 在初稿基础上整合 8 项增量建议(实时校验/复制按钮/命名建议/错误码 Tooltip/校验顺序/自动退出/驱动兜底/文本截断)及 4 节架构设计说明。V1.0 为 IT 部门单兵工具,聚焦"看电脑 + 改机器名"两件事,不做远程管理、不做 AD 域、不做历史回溯。

---

## 一、项目简介

### 1.1 项目名称
Windows 机器名修改工具(Computer Rename Tool)

### 1.2 项目背景
IT 人员在电脑初始化、资产登记及日常维护过程中,需要频繁修改计算机名称。Windows 系统默认修改流程较繁琐,需要进入系统设置后才能完成。为了提高工作效率,开发一款轻量级绿色工具,实现快速查看电脑信息及修改机器名。

### 1.3 适用场景
- 资产登记:新机入网、IT 资产建档
- 日常维护:机器名规范整改、字母大小写修正、重复名修正
- 故障定位:IT 远程协助时需要先看机器名
- 跨部门流转:机器名随使用者 / 部门变更

---

## 二、开发目标

开发一款绿色版 Windows 桌面工具,实现以下功能:
1. 查看当前机器名
2. 查看电脑基础硬件信息(CPU/内存/显卡/硬盘)
3. 修改机器名(含实时规则校验)
4. 自动检测管理员权限(无权限自动请求 UAC 提权)
5. 修改完成后提示重启电脑(立即重启 / 稍后重启 二选一)
6. 复制机器名(提升 IT 登记效率)
7. **【V1.0 新增】** 输入实时校验 + 建议名(可选,如部门有命名规范)
8. **【V1.0 新增】** 改名成功后自动退出 + 开机提醒(选"稍后重启"时)

## 四、界面设计

窗口尺寸建议:**600 × 450**
整体采用 Windows 11 风格,布局简洁,顶部 TitleBar + 中部 3 个 GroupBox + 底部状态栏。

### 1. 电脑信息区域

**标题**:当前电脑信息

**显示内容**:
- 当前机器名:D`ESKTOP-ABC123` [+ 复制按钮]
- Windows:`Windows 11 25H2`
- 当前用户:`Administrator`

### 2. 硬件信息区域

**标题**:电脑配置

**显示内容**(每行 标签:值):
- CPU:例如 `Intel Core i7-13700H`(**支持文本截断 + Tooltip**)
- 内存:例如 `32 GB`
- 显卡:例如 `NVIDIA RTX 4060 Laptop GPU`
  - 取第一块独立显卡;若无独立显卡,取集成显卡;**读取失败显示 "未知 (驱动未安装)"** 而非空
- 硬盘:仅显示系统盘所在硬盘,例如 `Samsung PM9A1 1TB SSD`

### 3. 机器名修改区域

**标题**:修改机器名

**输入框**:
- 高度 32px
- 右侧内嵌校验状态图标(✅ 绿 / ❌ 红 / ⚠️ 灰),**实时更新**(输入时即时反馈)
- 占位文字:`请输入新的机器名`

**建议名按钮**(如有命名规范):
- 文本:`建议:BJ-IT-001`(可配置)
- 点击:自动填入

**按钮**:
- 【修改机器名】

**底部提示**:
> 修改完成后需要重启电脑才能生效。

## 五、机器名规则(实时校验)

输入内容必须符合 Windows 计算机命名规范。

| 规则 | 校验 |
|---|---|
| 允许字符 | `A-Z` / `a-z` / `0-9` / `-` |
| 不允许 | 中文 / 空格 / `_` / `/` / `\` / `.` / 其他特殊字符 |
| 最大长度 | 15 个字符 |
| 不能为空 | 必填 |

**实时校验提示**(输入时立即反馈,不用等点提交):

| 触发 | 提示 | 图标 |
|---|---|---|
| 名称含非法字符 | `机器名只能包含字母、数字和 "-"` | ❌ |
| 超过 15 字符 | `机器名长度不能超过15个字符` | ❌ |
| 输入为空 | `请输入新的机器名` | ❌ |
| 与当前机器名一致 | `机器名未发生变化` | ⚠️ 灰 |
| 通过所有校验 | (无提示) | ✅ 绿 |

**校验顺序**:**不依赖管理员权限** — 用户未提权时也能在输入框看校验结果,只是改不了。

## 六、修改流程

1. 用户输入新机器名(实时校验)
2. 点击【修改机器名】
3. 弹确认框:
   ```
   是否确认修改机器名？

   当前：DESKTOP-ABC123
   新的：BJ-IT-001
   ```
4. 点【确定】→ 执行改名
5. 改名成功:
   ```
   机器名修改成功！

   需要重启电脑后生效。
   ```
   提供两个按钮:
   - 【立即重启】(60 秒倒计时,可取消)
   - 【稍后重启】(关弹窗,工具自动退出)
6. 选【立即重启】→ 60 秒倒计时 + 取消按钮
7. 选【稍后重启】→ 工具自动退出,下次开机弹 Toast 提醒:
   ```
   上次修改了机器名(BJ-IT-001),是否立即重启?
   ```

**失败处理**(第 4 步可能失败):
- 弹错误信息,显示具体异常(管理员权限不足 / 系统调用失败 / 网络错误)
- 工具保持打开,允许用户重试

## 七、管理员权限

程序启动时自动检测管理员权限。

**若没有管理员权限**:
- 弹出提示:
  ```
  修改机器名需要管理员权限。

  是否重新以管理员身份启动？
  ```
- 点【确定】→ 程序自动请求 UAC 提权
- 点【取消】→ 工具仍能查看电脑信息(只读模式),但【修改机器名】按钮置灰

**重要:管理员权限检查时机**
- ✅ 启动时:检测并提示提权
- ✅ 改名时:再次校验(防止期间被降权)
- ❌ 实时校验时:**不需要**(用户没权限也能校验)

## 八、异常处理

| 情况 | 提示 | 后续动作 |
|---|---|---|
| 输入为空 | `请输入新的机器名` | 焦点回到输入框 |
| 名称非法 | `机器名格式错误` + 具体原因 | 焦点回到输入框,光标定位到非法字符 |
| 修改失败 | `修改失败,请确认具有管理员权限。` | 工具保持打开,允许重试 |
| 系统调用失败 | 显示具体异常信息(含 HRESULT 0x... 错误码) | 工具保持打开 |
| CPU/内存/显卡/硬盘读取失败 | 显示"未知 (驱动未安装)"或"未知 (WMI 服务未启动)" | 工具仍能继续工作 |

**错误信息格式**:
```
[错误代码 0x80070005]
修改失败,访问被拒绝。

如需帮助请联系 IT 部门。
[详情] → 鼠标悬停显示完整堆栈
```

## 九、日志

程序目录自动生成 `Logs/` 文件夹,记录:

| 字段 | 示例 |
|---|---|
| 启动时间 | `2026-08-05 09:15:31` |
| 启动模式 | `Admin` / `User` |
| 修改前机器名 | `DESKTOP-ABC123` |
| 修改后机器名 | `BJ-IT-001` |
| 修改结果 | `成功` / `失败 (0x80070005)` |
| 异常信息 | 完整堆栈 |

**日志格式**(YAML-like,易读):
```
2026-08-05 09:15:31
启动程序: Admin
启动用户: Administrator

2026-08-05 09:16:02
修改机器名:
  DESKTOP-ABC123
  → BJ-IT-001
结果: 成功

2026-08-05 09:18:45
异常: 修改失败
  HRESULT: 0x80070005
  消息: Access is denied.
  堆栈: ...
```

**日志文件命名**:`rename-tool-YYYY-MM-DD.log`(按天分文件)

**保留策略**:保留最近 30 天,自动清理

## 十三、架构设计说明(新增)

### 13.1 技术栈
- **运行时**:.NET 8(单文件 publish,LTR 到 2026-11)
- **UI**:WPF + MVVM(无第三方 UI 库,降低打包体积)
- **硬件信息获取**:WMI(Win32_Processor / Win32_PhysicalMemory / Win32_VideoController / Win32_DiskDrive)
- **机器名修改**:`Microsoft.Win32.SafeNativeMethods` + `Kernel32!SetComputerNameExW`
- **管理员提权**:`Process.Start` + `runAs` verb 触发 UAC
- **剪贴板**:`System.Windows.Clipboard`
- **日志**:自写 Logger(单文件,无 NLog/log4net 依赖)

### 13.2 分层架构

```
┌─────────────────────────────────────┐
│  Views(XAML + UserControls)         │  纯 UI,数据绑定
├─────────────────────────────────────┤
│  ViewModels(ObservableObject)      │  状态管理 + 业务编排
├─────────────────────────────────────┤
│  Services(系统调用 / WMI / 日志)     │  依赖倒置,接口注入
├─────────────────────────────────────┤
│  Models(数据模型)                    │  POCO,无依赖
└─────────────────────────────────────┘
```

### 13.3 状态机(改名流程)

```
[Idle] ─点击改名─→ [Validating] ─通过─→ [Confirming] ─确定─→ [Renaming] ─成功─→ [RebootPrompt]
                       │                  │                    │                │
                       │非法              │取消                │失败            │立即重启
                       ↓                  ↓                    ↓                ↓
                  [Idle+Error]        [Idle]            [Error+Retry]      [Rebooting]
                                                                              │
                                                                              稍后重启
                                                                                 │
                                                                                 ↓
                                                                              [Exit]
```

### 13.4 异常映射表(新增)

| 异常源 | HRESULT | 错误码 | 用户提示 |
|---|---|---|---|
| Access Denied | 0x80070005 | 5 | 修改失败,请确认具有管理员权限。 |
| Invalid Name | 0x8007007B | 123 | 机器名格式错误 |
| Network/Active Directory | 0x8007089A | 2202 | 当前网络环境不允许修改机器名 |
| Privilege Not Held | 0x80070005 | 5 | 修改失败,请确认具有管理员权限。 |
| Shutdown Failure | 0x80070015 | 21 | 启动重启失败,请手动重启 |
| WMI Service Stopped | 0x80041010 | -2147217408 | 硬件信息读取失败(WMI 服务未启动) |
